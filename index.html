Notes on performance

The chart compares the indexed development of the AbaInvest portfolio against an Oslo Børs index proxy. Data in this version is static and illustrative.

  • Portfolio line shows cumulative return based on the holdings data defined in the script.
  • Benchmark line approximates the Oslo Børs over the same period.
  • To connect live data later, you can replace the static arrays in script.js with data from an API or spreadsheet export.

About AbaInvest

AbaInvest is a personal investment portfolio with a focus on long-term ownership in quality companies listed on the Oslo Stock Exchange and selected international markets. This dashboard is built to give a clear, calm overview of the portfolio without the noise of intraday trading.

All figures and returns shown here are for personal tracking purposes only and do not constitute investment advice.
